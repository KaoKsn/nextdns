# µconfig

Create and customized NextDNS profile using your API.

`main.py`

    Creates a new profile using the configurations present in the configuration file you provide.
    Customize the configuration file as required.

`info.py`

    Information about different endpoints that NextDNS provides.

`readme`

    Information about this µ-project

`configs/`

    Directory that contains configuration files which are used to create new profiles.

`results/`

    Directory that contains JSON response from the server.
